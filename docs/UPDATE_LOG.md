# KawAIi Code リリースノート

## v1.0.0-beta - ベータ版アップデート 🔄

KawAIi Codeベータ版に大幅なアップデートを実施しました！
複数のAIアシスタント対応と音声システムの統合により、より安定した開発体験を提供します。

## ✨ 新機能・改善

### 🤖 マルチAI対応
- **Claude Code**: Anthropic社の公式CLIツール
- **Claude Code (Dangerous)**: 上級者向け高権限モード  
- **Gemini CLI**: Google Gemini統合
- **Codex**: OpenAI Codex統合

### 🎭 3Dキャラクター「モネ」
- VRMモデルによるリアルタイム表情変化
- 音声に同期した自然な口パクアニメーション
- 感情分析による豊かな表現力

### 🔊 統合音声システム
- 全AIで統一された◆◇マーカー音声読み上げ
- AivisSpeech Cloud/Local両対応
- 重複読み上げ防止システム
- 音声合成モデル追加機能実装

### 🎨 カスタマイズ機能
- キャラクター性格設定（CLAUDE.md等）
- 作業ディレクトリ自由設定
- MDファイル一括管理

### 🔧 開発者体験
- タブ型ターミナルインターフェース
- リアルタイム接続状態監視
- メモリ最適化とパフォーマンス向上
- エラーハンドリング強化
